品牌简介

直通云(ZTCloud)是面向个人与团队的专业网络加速品牌，提供稳定的机场订阅与VPN梯子服务。我们通过精选全球节点、IPLC 内网专线与优化 BGP 线路，帮助用户流畅观看高清流媒体、降低游戏延迟，并在跨境办公时保持可靠连接。直通云官方网站集中展示套餐、客户端选择与操作指南，方便完成从订阅到连线的全流程。

服务覆盖香港、日本、新加坡、美国与欧洲等核心区域，支持 Clash、Shadowrocket、v2rayN 等主流客户端一键导入。旗舰线路针对原生流媒体解锁与游戏加速做了专项优化，团队用户还可申请定制路由与专属支持。

客户端下载与选择

直通云机场订阅兼容主流代理客户端，不绑定单一软件。请按设备选择官方或社区稳定版本，安装后粘贴订阅链接即可拉取节点。强调正确选择客户端，是保证解锁与速度的关键一步。

桌面端

Windows：推荐 Clash Verge 或 v2rayN。导入 Clash / VMess 订阅后开启系统代理或 TUN，可按域名分流。

macOS：推荐 ClashX Meta 或 Surge。支持菜单栏快捷切换节点，适合长期挂机办公。

Linux：可使用 Clash Premium 或 mihomo 内核，配合订阅自动更新。

移动端

Android：推荐 Clash Meta for Android 或 NekoBox，支持分应用代理，游戏与浏览器可分别走加速。

iOS：推荐 Shadowrocket、Stash 或 Quantumult X。部分应用需外区商店获取，导入后即可使用直通云节点。

操作说明

1. 获取机场订阅

在直通云官网选定套餐并完成支付，于用户中心复制 Clash、V2Ray 或 Shadowrocket 格式订阅链接。年付用户可一次配置长期使用。

2. 安装对应客户端

根据上一节选择 Windows、macOS、Android 或 iOS 工具并完成安装。首次打开时允许 VPN / 网络扩展权限，否则无法接管系统流量。

3. 导入并更新节点

在客户端「订阅」或「配置」中粘贴链接并更新。部分软件支持二维码。更新成功后可见香港、日本、新加坡、美国等节点列表。

4. 连接与日常维护

选择延迟较低的节点开启连接，需要全局时启用 TUN。定期点击更新订阅以获取新线路。旗舰与团队版工单优先处理连线异常。

常见问题

直通云(ZTCloud)是官方机场还是VPN服务？

直通云同时提供机场订阅（多节点池与规则分流）和接近传统VPN的一键连接体验。用户可在 Clash、Shadowrocket 等客户端中灵活使用。官方网站统一提供订阅说明与客户端选择指引，便于核对正版渠道。

如何下载直通云推荐的客户端？

请在本页「客户端下载与选择」查看各系统推荐软件。桌面端与安卓可从对应项目发布页获取，iOS 需通过应用商店安装。直通云不强制捆绑安装包，避免版本滞后，导入本站订阅即可使用全部节点。

各套餐流量与设备数如何理解？

基础版每月 100GB、3 台设备，适合浏览与轻度视频；旗舰版 300GB、5 台设备，覆盖 4K 流媒体与游戏加速；团队版 1000GB、20 台设备，面向工作室或家庭共享。流量按代理出口统计，年付价格更优惠，用量不足时可升级。

节点覆盖哪些地区？游戏加速怎么用？

线路以东亚（香港、日本、韩国、台湾）、新加坡、美国西岸及欧洲精选机房为主。旗舰版起提供 IPLC 专线，可将游戏走加速、其余流量直连或走普通节点，从而兼顾延迟与日常访问。

订阅链接泄露或需要更换怎么办？

立即在用户中心重置订阅，旧链接随即失效。直通云支持随时重置。请勿在社交平台或群组公开个人订阅地址，以免流量被盗用。

是否记录日志？隐私如何保障？

实行无日志政策，不保存访问记录与流量内容，传输全程加密。请通过本官方网站核对套餐与客户端说明，避免仿冒站点。

年付和月付如何选择？

年付大约相当于减免两个月费用（如基础版年付 ¥150）。轻度使用选基础版；需要原生解锁与 IPLC 游戏优化选旗舰版；多人高流量或需要定制路由选团队版并使用专属支持。
